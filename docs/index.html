Goselaz Household Dashboard

This is a private, single-household dashboard application built and run by its owner for personal use on a Raspberry Pi. It displays the day's calendar, weather, sports scores, and household information on a wall-mounted screen.

It is not a public product or service, and it is not intended for use by anyone outside the household that runs it.

See the privacy policy for details on how this app uses Google Calendar data.
