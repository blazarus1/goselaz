Privacy Policy

Last updated: September 2026

Goselaz Household Dashboard is a personal, single-household application. It is not a commercial product, is not distributed to the public, and is used only by its owner on a Raspberry Pi inside their home.

What data this app accesses

With the account owner's permission, the app connects to the Google Calendar API using read-only access (calendar.readonly) to display the owner's own calendar events on the dashboard. It does not access any other Google account data, and it does not access any other person's calendar.

How the data is used and stored

Calendar event data is fetched periodically and cached locally in a SQLite database on the Raspberry Pi that runs the dashboard, solely to display upcoming events. This data is never transmitted to any third party, sold, or used for advertising or analytics of any kind.

Revoking access

Access can be revoked at any time from the Google Account security settings at myaccount.google.com/permissions .
